## 5. Спорные случаи и комментарии

- **«heartbeat»** — оставляем латиницей в контексте Raft и health-check, потому что «сигнал жизни» звучит вычурно и не используется в индустрии.
- **«service mesh»** — отрасль не выработала русского эквивалента.
- **«feature store», «champion-challenger»** — то же самое, оставляем.
- **«push-уведомления»** — единственный случай, когда `push` оставлен; устоявшийся пользовательский термин.
- **«token bucket», «leaky bucket»** — оставляем как имена алгоритмов (с пояснением в скобках при первом упоминании).
- **«split-brain», «fan-out», «backpressure», «cache stampede», «failover», «handshake», «watermark»** — в скобках при первом упоминании в каждом файле, потом — русский вариант.
- **«vector clock» → «векторные часы»** (не «таймстампы»).
- **«atomic clocks» → «атомарные часы»** (не «атомные»).
- **«durability» → «живучесть»** (не «долговечность»).
- **«estimation» → «оценка»** (не «прикидка»).
- **«DC / datacenter» → «ЦОД»**.
- **«counter» → «счётчик»**.
- **«mitigation» → «способ защиты / противодействие»** (не «митигация»).
- **«linearizable» → «строгая согласованность (linearizable)»** при первом упоминании, потом — «строгая».
- **«tiebreaker» → «разрешение ничьей»**.
- **«ratio» → «отношение»**.
- **«recall» → «полнота»** (метрика поиска).
- **«rebuild» → «перестроение»**.
- **«collaborative filtering» → «коллаборативная фильтрация»**.
- **«content-based» → «на основе содержимого»**.
- **«max leading zeros» → «максимум ведущих нулей»**.
- **«surge» → «надбавка»** (с пояснением «surge» в скобках при первом упоминании в DESIGN_04).
- **«sloppy quorum + hinted handoff»** — оставить термины, при первом упоминании дать русскую расшифровку: «нестрогий кворум с подсказанной передачей».
- **«fencing token»** — оставить английский с пояснением «токен ограждения».
- **«joint consensus»** — оставить с пояснением «совместный консенсус».
- **«lease-based»** — заменить на «через временную аренду (lease)».
- **«join semilattice»** — оставить только при необходимости с пояснением «полурешётка слияния».
- **«leaderless multi-region»** — заменить на «multi-region без выделенного лидера».
- **«webhook»** — латиницей в каждом файле; не использовать вариант «вебхук» в одном файле с «webhook».
