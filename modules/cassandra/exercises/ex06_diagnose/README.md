# Ex06 — Диагностика медленного чтения

## Условие

Дежурный получил жалобу: страница «мои заказы» открывается 2 секунды у отдельных пользователей,
у большинства — мгновенно. Кластер здоров: узлы в строю, компактизация не идёт, процессор
не загружен. Метрика задержки чтения по кластеру в норме, но 99-й процентиль вырос втрое.

## Задание

Найди причину, опираясь только на инструменты кластера — без доступа к коду приложения.
Порядок действий и настоящие выводы команд запиши в `investigation.md`.

## Критерии приёмки

- [ ] Приведена последовательность из **минимум четырёх** диагностических шагов, каждый
      с настоящим выводом команды и с выводом, который из него следует.
- [ ] Объяснено, почему средняя задержка осталась в норме, а хвост вырос.
- [ ] Названы минимум три возможные причины такой картины, и показано, как каждая
      отличается от остальных по наблюдаемым признакам.
- [ ] По трассировке определено, сколько узлов участвовало в запросе и на каком шаге ушло время.
- [ ] Предложено исправление и способ убедиться, что оно подействовало.
