# behavioral-interview — Roadmap

Модуль отвечает на вопрос «что сказать вслух». Механизмы (WSJF, закон Литтла, DoD, DORA)
живут в [`engineering-process`](../engineering-process/) и здесь только цитируются ссылкой.

## Как этим пользоваться

Линейно читать не нужно. Точка входа — [theory/QUESTION_INDEX.md](theory/QUESTION_INDEX.md):
список вопросов, у каждого строка ядра ответа и ссылка на разбор. Открывается за десять минут
до собеседования.

## Порядок прохождения

| Приоритет | Тема | Частота на собеседованиях |
|-----------|------|---------------------------|
| 1 | Индекс вопросов: что вообще спрашивают и где это разобрано | — |
| 2 | Рамки ответа: STAR/STARL для историй, размен для решений | ★★★★★ |
| 3 | Люди: конфликт, критика, обратная связь, наставничество | ★★★★★ |
| 4 | О себе: провал, ошибка, давление, незнакомое | ★★★★★ |
| 5 | Менеджерские: объём, сроки, оценки, приоритет | ★★★★★ |
| 6 | Менеджерские: качество и риск выкатки | ★★★★ |
| 7 | Менеджерские: процесс и коммуникация | ★★★★ |
| 8 | HR-раунд: почему уходишь, мотивация, вопросы к работодателю | ★★★★ |

## Модуль 1: Индекс вопросов

📖 [theory/QUESTION_INDEX.md](theory/QUESTION_INDEX.md)

- [ ] Все разбираемые вопросы одним списком: вопрос → ядро ответа → ссылка на разбор
- [ ] Группировка по раунду: HR, поведенческий, менеджерский
- [ ] Что делать, если вопроса нет в списке

## Модуль 2: Рамки ответа

📖 [theory/ANSWER_FRAMES.md](theory/ANSWER_FRAMES.md)

- [ ] STAR / STARL: механика ответа-истории на «расскажи о случае, когда…»
- [ ] Где STAR ломается и почему буква L решает больше остальных
- [ ] Рамка решения: уточнить → назвать критерий → предложить размен → зафиксировать
- [ ] Когда какая рамка: прошедшее время → STAR, гипотетическая ситуация → размен
- [ ] Красные флаги в самом вопросе
- [ ] Когда правильный ответ — просто согласиться

## Модуль 3: Люди

📖 [theory/BEHAVIORAL_PEOPLE.md](theory/BEHAVIORAL_PEOPLE.md)

- [ ] Конфликт с коллегой — и почему «конфликтов не было» это красный флаг
- [ ] Приём критики на свой код и своё решение
- [ ] Подача тяжёлой обратной связи
- [ ] Объяснить сложное нетехническому человеку
- [ ] Джун делает медленно, переписывать быстрее
- [ ] Блокировка другой командой
- [ ] Несогласие с принятым решением: disagree and commit
- [ ] Bus factor: ты единственный, кто знает сервис

## Модуль 5: Менеджерские — объём и сроки

📖 [theory/MANAGERIAL_SCOPE.md](theory/MANAGERIAL_SCOPE.md)

- [ ] Бизнесу нужно пять задач, а команда тянет две
- [ ] Середина спринта, ничего не успеваем
- [ ] Два стейкхолдера принесли по P0
- [ ] Оценка занижена вдвое, срок назван клиенту
- [ ] «Дай оценку прямо сейчас»

- [ ] Оцени задачу в незнакомой области (спайк)
- [ ] Сказать «нет» старшему стейкхолдеру
